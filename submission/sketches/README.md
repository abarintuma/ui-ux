# Interface sketches

These are simple **digital wireframes** created as drawing guides for the assignment. They document the existing journey and are not claimed to be original paper sketches or evidence of an earlier design activity.

## How to make the required paper sketches

Draw three phone outlines on paper. Copy the main boxes and labels from the guide. For the third screen, show the form and add a small note explaining the saved summary. Label the important buttons and draw arrows for Login → Dashboard → Add transaction → Summary. Photograph the drawings and place the photos in this folder if the lecturer requires paper evidence.

## What each sketch explains

1. Login: where to enter email and password and how to continue.
2. Dashboard: where to see income, expenses and balance and find Add transaction.
3. Add transaction: the fields to complete, Save and Cancel, and the updated totals after saving.
